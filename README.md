# LoomLoom 美股价值初筛 Skill

基于段永平式长期价值投资框架，对美股候选池进行结构化初筛。

## 包含内容

- `index.html`：静态介绍页，直接打开即可预览。
- `loomloom-us-value-screening-skill-v2.zip`：可下载的 v2 Skill 包。
- `skill/`：v2 Skill 的解压源码，便于审查与协作。
- `docs/brand-spec.md`：页面视觉与素材说明。

## 工作方式

1. 准备股票代码或标准化财务指标表。
2. 由 LoomLoom 云端并行审查候选池。
3. 通过本地证据校验、否决项与复跑条件合并结果。
4. 仅输出可供进一步人工研究的优先级，不构成投资建议。

## 使用 Skill

下载 `loomloom-us-value-screening-skill-v2.zip`，解压并按其中的 `SKILL.md` 安装到本地 Agent。
